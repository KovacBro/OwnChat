## OwnChat 0.1.0

First public baseline — a local-first, multi-model desktop chat client.

![OwnChat](https://github.com/KovacBro/OwnChat/raw/main/docs/assets/app-preview.png)

### Highlights

- Three-column desktop UI built for Microsoft Edge `--app` windows.
- Each conversation binds its own provider, model, and persona.
- Direct WorkBuddy integration through the local `dsh-connect-workbuddy`
  credential store — no 8787 gateway, no separate WorkBuddy Key.
- WorkBuddy CN and Global slots; 21 models were available on the development
  account, including `hy3`, `glm-5.3-flash`, and `deepseek-v4.1-flash`.
- Streaming, stop, retry, copy, reasoning blocks, Emoji, and image input.
- Full provider config: Base URL, Key, model, context, temperature, headers,
  custom body, vision, test connection, and model discovery.
- Presets for OpenRouter, Gemini, Groq, SiliconFlow, Zhipu, ModelScope,
  Mistral, Cerebras, GitHub Models, Ollama, and custom endpoints.
- Three original AI personas (DeepSeek娘 / GLM娘 / Hy3娘) plus an avatar
  studio with preset prompts and optional image APIs.
- WorkBuddy download center: official installer, pause/resume, SHA-256, and
  Authenticode signature verification.
- Local-first storage; API keys encrypted with AES-256-GCM and never returned
  to the browser.
- Windows installer bundles Node.js; no separate Node installation required.

### Install

Download `OwnChat-0.1.0-win64-setup.exe` from Assets and run it. The installer
is per-user (`%LOCALAPPDATA%\Programs\OwnChat`) and does not require admin
rights. A portable ZIP is also provided.

> The OwnChat installer is not code-signed yet. Windows SmartScreen may show
> “Unknown publisher”. Verify `SHA256SUMS.txt` before running.

### Requirements

- Windows 10/11 x64.
- Microsoft Edge for the app window.
- For WorkBuddy models: WorkBuddy desktop signed in, plus the DSH
  `dsh-connect-workbuddy` plugin installed in the desktop profile.

### Notes

- Voice is not part of the product roadmap.
- File and screenshot sending are not available yet.
- Claude can be used through OpenRouter or another OpenAI-compatible gateway.
- The installer leaves `data/` in place on uninstall.

### Checksums

See `SHA256SUMS.txt` in Assets.
