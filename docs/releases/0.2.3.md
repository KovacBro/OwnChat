# OwnChat 0.2.3

This is a patch release with an installer, because the 0.2.3 migration has to
reach existing installs. It removes the old local third-party credential bridge
and replaces manual endpoint setup with provider presets.

## What changed

- **Pick a provider, paste a key.** DeepSeek, Alibaba Bailian, Volcengine Ark,
  Zhipu BigModel, Kimi, Tencent Hunyuan, SiliconFlow, OpenRouter, Gemini, Groq,
  Mistral, GitHub Models, Ollama, Azure OpenAI and a custom endpoint all have a
  preset with the base URL already filled in.
- **Setup steps are in the form.** Each preset links to its console and API docs,
  and lists the 3–4 steps needed to create a key. No separate tutorial is needed.
- **Model discovery is automatic.** After saving, OwnChat calls the provider's
  `/models` endpoint and fills the model picker. If the provider does not expose
  a list, the form says so instead of silently failing.
- **The old local credential bridge is gone.** OwnChat no longer reads another
  application's login state, and no longer bundles a downloader or installer
  runner for a third-party desktop client.
- **Local API hardening.** The server still binds to `127.0.0.1`, but API calls
  now need a token generated at launch; `Origin`/`Host` are checked, and
  state-changing requests must use JSON.
- **Upgrade cleanup.** Providers, personas and conversations that pointed at the
  removed bridge are unbound on startup. Their messages are preserved; select a
  new model before sending again.

## Upgrade

Install over 0.2.2. `data/` is preserved. Conversations from the removed provider
will show “未绑定接口” until you pick a new model from **API**.

## Assets

- `OwnChat-0.2.3-win64-setup.exe`
- `OwnChat-0.2.3-win64-portable.zip`
- `SHA256SUMS.txt`

The installer is not code-signed. Windows SmartScreen may show “Unknown
publisher”; verify the SHA-256 values in `SHA256SUMS.txt` before running it.
