## OwnChat 0.2.0

Reliable daily driver. No new dependencies, no cloud, no telemetry.

![OwnChat](https://github.com/KovacBro/OwnChat/raw/main/docs/assets/app-preview.png)

### Highlights

- **Dark theme** — follow the system, or force light / dark.
- **Full-text search** across every message, with snippets and jump-to-conversation.
- **Archive** conversations; the sidebar switches between the active and archived
  lists.
- **Per-model capabilities** — vision, context window, max output and reasoning
  effort are editable per model and survive a `/models` refresh.
- **One-shot automatic retry** on network / 429 / 5xx failures, before the first
  token, so a failed turn never leaves a duplicate message.
- **Copyable diagnostic code** on every provider error — paste it into an issue.
- **Token usage** per reply, a **context-trim notice**, and a toggle to hide usage.
- **Export a conversation**, **import a workspace** (merges, never overwrites),
  and **bulk delete** with confirmation.
- **Update check** against GitHub Releases, and the installed version in Settings.

### Changed

- **License: MIT → AGPL-3.0.** `v0.1.0` and earlier remain MIT; that grant is
  irrevocable. `0.2.0` and later are AGPL-3.0-or-later.
- The installer now stops a running instance before upgrading. `data/` is never
  touched by install, upgrade or uninstall.
- Model lists are merged instead of replaced, so hand-edited capabilities are
  kept.
- WorkBuddy provider cards show region, signed-in account, token expiry and model
  count.

### Install

Download `OwnChat-0.2.0-win64-setup.exe` from Assets and run it. Existing users
can install over the top: the app is closed automatically and `data/` is
preserved. A portable ZIP is also provided.

> The installer is still not code-signed. Windows SmartScreen may show
> “Unknown publisher”. Verify `SHA256SUMS.txt` before running.

### Notes

- Upgrading from 0.1.0 keeps every conversation; no migration step is required.
- Voice is not part of the product roadmap.
- Very long conversations still render in one pass.
- 1,000-message conversations and dark-theme contrast still need a manual
  verification pass.
