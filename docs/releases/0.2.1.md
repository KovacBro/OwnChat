## OwnChat 0.2.1

Three direct-connect presets for domestic platforms. **求索 / 百炼 / 方舟** are
independent of the persona system — they use the plain assistant persona and
create a conversation in one click.

### Added

**求索** — `https://api.deepseek.com/v1`
General chat and writing. Strong Chinese, few but stable models
(`deepseek-chat`, `deepseek-reasoner`), pay per token.

**百炼** — `https://dashscope.aliyuncs.com/compatible-mode/v1`
Long context and multimodal. The full Qwen line
(`qwen-plus`, `qwen-max`, `qwen-vl`), for long documents, image input and
stable enterprise-grade calls.

**方舟** — `https://ark.cn-beijing.volces.com/api/v3`
Doubao models, aimed at role-play and voice scenes. Create an inference endpoint
in the Ark console first, then use the `ep-…` ID as the model name.

Other changes:

- The “new conversation” dialog is split into **persona / platform / any model**.
  Platform cards show their state (not configured, waiting for models, N models);
  clicking one before it is configured opens the prefilled provider form.
- A built-in `助手` persona (hidden from the persona list) backs the platform
  presets.

### Fixed

- Existing installs get the `助手` persona added automatically on upgrade.

### Notes

- No keys are bundled and no accounts are created. Get a key from each platform.
- “求索” is only the display name; the endpoint is still DeepSeek's official API.
- The project rule says only `MAJOR.MINOR.0` ships installers. This patch ships
  one anyway so existing 0.2.0 users can upgrade in place; the rule will be
  revisited.

### Install

Download `OwnChat-0.2.1-win64-setup.exe` and install over 0.2.0 — `data/` is
preserved. A portable ZIP is also provided.

> The installer is still not code-signed. SmartScreen may show “Unknown
> publisher”; verify `SHA256SUMS.txt`.
